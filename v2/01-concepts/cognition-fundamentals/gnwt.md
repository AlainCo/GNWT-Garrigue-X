 
## GNWT (Global Neuronal Workspace Theory)

### Résumé
  
Le GNWT décrit un espace de travail global où certaines informations deviennent **accessibles à l’ensemble du système** après une ignition.  
Il constitue le niveau où la coordination, la décision et la diffusion des informations critiques ont lieu.  

- Pourquoi ce concept existe  
→ expliquer comment une information devient globalement accessible (consciente fonctionnelle)  

- Ce qu'il apporte  
→ un mécanisme d’intégration et de diffusion à grande échelle  

- Pourquoi il est important pour Garrigue-X  
→ il permet la **coordination globale entre modules autonomes**  

### Idée essentielle
  
Question à laquelle le concept répond :  
Comment un système distribué peut-il agir de manière cohérente et unifiée ?

Réponse courte :  
En disposant d’un espace global où les informations importantes sont partagées après une ignition.

### Description
  
Le GNWT est un espace de travail où :
- les informations sélectionnées sont diffusées globalement  
- plusieurs modules peuvent accéder simultanément à ces informations  
- les décisions sont prises à partir de contenus partagés  

Il ne traite pas toutes les informations :
- seules celles qui ont déclenché une **ignition** y accèdent  

Principes importants :
- accès global limité  
- diffusion sélective  
- compétition entre informations  
- intégration multi-modules  

Mécanismes :
- réception des ignitions provenant des modules  
- mise en compétition des contenus (attention)  
- sélection des contenus dominants  
- diffusion globale (broadcast)  
- utilisation par les modules (planner, mémoire, etc.)  

Propriété clé :
- le GNWT n’est pas un flux continu  
- il est activé de manière **événementielle via les ignitions**  

### Intérêt pour Garrigue-X
  
Dans l’architecture :
- le GNWT est présent à partir des niveaux N ≥ 4
- il reçoit des **résumés d’ignition compressés** provenant des niveaux inférieurs
- il permet une **coordination entre modules cognitifs spécialisés**  
- il sert de base au processus de décision global  

Exemples :
- un signal critique remonté par un module est diffusé à l’ensemble du système  
- plusieurs modules accèdent à une même information pour prendre une décision cohérente  
- un événement local devient une information stratégique globale  

Limites connues :
- capacité limitée (risque de saturation)  
- dépendance à la qualité des ignitions  
- coût computationnel du broadcast global
