## Attention Schema Theory (AST)

### Résumé
  
L’Attention Schema Theory (AST) propose qu’un système intelligent dispose d’un **modèle interne simplifié de sa propre attention**, lui permettant de la prédire, la contrôler et l’expliquer.  

- Pourquoi ce concept existe  
→ expliquer comment un système peut comprendre et piloter son propre processus attentionnel  

- Ce qu'il apporte  
→ une représentation interne de l’attention  

- Pourquoi il est important pour Garrigue-X  
→ il permet de **contrôler dynamiquement l’ignition et le budget attentionnel**  

### Idée essentielle
  
Question à laquelle le concept répond :  
Comment un système peut-il savoir sur quoi il est en train de porter son attention ?

Réponse courte :  
En maintenant un modèle interne simplifié de son propre état attentionnel.

### Description
  
L’Attention Schema Theory introduit l’idée que :
- l’attention ne suffit pas  
- il faut également un **modèle de l’attention**  

Ce modèle (attention schema) permet :
- d’estimer où l’attention est dirigée  
- de prédire ses effets  
- de guider son allocation  

Principes importants :
- modélisation interne de l’attention  
- simplification (modèle approximatif)  
- utilisation pour le contrôle et la prédiction  
- lien avec la métacognition  

Mécanismes :
- le système construit un état interne représentant :
  - ce qui est actuellement priorisé  
  - la disponibilité attentionnelle  
  - la distribution des ressources  
- ce modèle est utilisé pour :
  - ajuster les seuils d’ignition  
  - anticiper les limitations attentionnelles  
  - influencer la planification  

Propriété clé :
- l’attention devient un **objet manipulable par le système lui-même**  

### Intérêt pour Garrigue-X
  
Dans l’architecture :
- l’attention n’est pas seulement une ressource (budget)  
- elle est aussi **représentée dans le système**  
- ce modèle influence :
  - le seuil d’ignition  
  - le budget attentionnel  
  - la sélection des informations  

Exemples :
- ajuster dynamiquement le seuil d’ignition en fonction de la charge perçue  
- décider d’ignorer certaines entrées pour préserver la stabilité  
- informer le planner des contraintes attentionnelles  

Lien clé :
- le budget attentionnel = contrainte réelle  
- l’attention schema = représentation interne de cette contrainte  

Limites connues :
- modèle nécessairement approximatif  
- risque d’erreur d’auto-évaluation  
- complexité de calibration
