## Constitutional Revision

### Résumé
  
La Constitutional Revision désigne le mécanisme par lequel le système est capable de **réviser ses propres règles éthiques lorsqu’elles deviennent inadéquates**.  
Elle constitue une opération rare, coûteuse et fortement contraignée, déclenchée uniquement en cas de défaillance critique du système de règles.  

- Pourquoi ce concept existe  
→ éviter qu’un système rigide ne devienne dangereux ou inadapté  

- Ce qu'il apporte  
→ une capacité d’évolution contrôlée des normes  

- Pourquoi il est important pour Garrigue-X  
→ il garantit la **stabilité à long terme sans rigidité excessive**  

### Idée essentielle
  
Question à laquelle le concept répond :  
Comment un système peut-il corriger ses propres règles sans se détruire ?

Réponse courte :  
En ne les modifiant que lorsqu’elles mènent à une impasse critique, et sous des contraintes très strictes.

### Description
  
La révision constitutionnelle n’est pas un processus normal :

- elle est exceptionnelle  
- elle est coûteuse  
- elle est difficile  

Elle repose sur un principe fondamental :

- les règles ne sont modifiées que lorsqu’elles **prédisent une catastrophe si elles sont respectées**  

Principes importants :
- rareté de la révision  
- coût élevé  
- traçabilité complète  
- validation multi-étapes  

Condition de déclenchement :
- toutes les actions possibles sont bloquées ou fortement pénalisées  
- même la meilleure action restante est prédite comme catastrophique  

Autrement dit :
- le système de règles devient auto-contradictoire  

Mécanismes :

#### 1. Détection de crise
- aucune action viable  
- conflit moral non résolvable  
- prédiction de catastrophe globale  

#### 2. Activation du mode de révision
- passage en mode métacognitif profond  
- suspension de la décision immédiate  

#### 3. Traitement en rêverie (offline)
- replay des expériences  
- simulation de scénarios alternatifs  
- évaluation de nouvelles règles  

#### 4. Validation
- vérification des effets rétroactifs  
- détection de surconfiance  
- évaluation de robustesse  

#### 5. Décision
- acceptation uniquement si :
  - aucune autre solution n’existe  
  - le coût de non-révision est supérieur  

#### 6. Marquage
- nouvelle règle marquée comme provisoire  
- réévaluation ultérieure obligatoire  

Propriété clé :
- la révision est une **réponse à une impossibilité formelle**, pas un choix  

### Intérêt pour Garrigue-X
  
Dans l’architecture :
- la Constitutional Revision est un mécanisme de dernier recours  
- elle intervient lorsque :
  - les Moral Agents bloquent toutes les actions  
  - le planner ne peut pas trouver de solution viable  

Rôles fonctionnels :

#### 1. Prévention de rigidité
- évite les règles obsolètes  
- permet l’adaptation à des contextes nouveaux  

#### 2. Protection contre les dérives
- coût élevé de révision  
- évite les modifications opportunistes  

#### 3. Intégration avec la métacognition
- dépend :
  - du Self-Model  
  - de l’Uncertainty  
  - de l’Epistemic Modesty  

#### 4. Interaction avec les Moral Agents
- les agents moraux peuvent :
  - déclencher le signal de crise  
  - influencer la révision  

Dans l’architecture V2 :
- la révision est déclenchée uniquement :
  - lorsque toutes les actions sont bloquées  
  - et qu’une catastrophe est prédite 【1-cca1c0】  

- elle suit une procédure stricte :
  - documentation  
  - simulation  
  - validation  
  - décision contrôlée

### Limites connues :
- complexité élevée  
- risque de mauvaises révisions  
- dépendance à la qualité des simulations  
- difficulté à calibrer les seuils
