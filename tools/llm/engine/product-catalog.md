# List of LLM engine used, tested, considered

## Tested

- [Llama.cpp - Run LLM Inference in C_C++](https://llama-cpp.com/)
  - API : [OpenAI](https://github.com/openai/openai-openapi)
  - Less flexible than Ollama, but with scripts it's still easy
  - Finally I found it easier for me to use, because it is more explicit
  - I have added start scripts

- [Ollama](https://ollama.com/)
  - API : [Ollama](https://github.com/ollama/ollama/blob/main/docs/api.md)
  - very flexible, can download and select model if you change model name in API call.
